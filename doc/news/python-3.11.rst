**Changed:**

* Changed the minimum versions of dependencies to the first releases that support Python 3.11: astropy 5.0.5, matplotlib 3.6, and pandas 1.5.
* Changed the supported astropy versions to include astropy 8, in line with svgdigitizer.

**Removed:**

* Removed support for Python 3.10, which reached its end of life in October 2026. unitpackage now requires Python 3.11 or later.
